# Examples

Manifests for shapes of project people actually have. Each is valid against
Kiln 0.1.0 — `kiln -C examples/node-app doctor` passes on all of them.

| Example | Shape |
| --- | --- |
| `node-app` | A single JavaScript service. |
| `python-app` | A single Python service. |
| `fullstack` | Both runtimes, plus services this release reports but does not manage. |
